Cost & FinOps

Multi-cloud FinOps

CloudParity

Problem
Comparing the same workload across AWS, Azure and Google Cloud means matching instance types and price sheets by hand.
Built
An app that sizes a workload, maps it to equivalent compute, database and storage services on each cloud, and adds performance benchmarks, forecasts and an AI advisor.
Gives you
A side-by-side hourly, monthly and annual cost comparison that can be exported as a report.

Azure Invoice Consolidator

Problem

Built
An app that merges the exports into one view with monthly trends, reservation coverage and an assistant for questions. Files stay in the browser.

FinOps game

CloudBounty

Problem
